# ASCII-Voice3

A Kaleidae node sparked by the submission:

> **ASCII starts to move.**
>
> An experiment in turning short phrases into moving ASCII art. Type a simple prompt and watch letters, symbols, and shapes begin to dance.

Scaffolded from the `vite-react` template — React + TypeScript on Vite. No router, no SSR — just a single SPA. Gut everything in `src/` and rebuild from scratch if it helps.

## Run

```bash
npm install
npm run dev
```

Open the URL it prints (usually `http://localhost:5173`).

## Build

```bash
npm run build      # typecheck + production build to dist/
npm run preview    # serve the built dist/ locally
```

## Push back to Kaleidae

```bash
kaleidae push "first version"
```

Your work appears in the thread the moment the push lands.
